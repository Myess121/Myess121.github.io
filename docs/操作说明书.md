## 1. 先理解三件事

**① 文章就是文件。** 每篇文章是一个文件夹，里面一个 `index.md` 文件（正文）加上这篇文章用到的图片：

```
content/post/
├── blog-setup/          ← 一篇文章
│   ├── index.md         ← 正文
│   └── cover.jpg        ← 图片
└── my-first-note/       ← 另一篇文章
    └── index.md
```

**② 你电脑上的改动，别人看不到。** 只有执行“发布”（`git push`）之后，GitHub 才会自动把网站更新。

**③ 发布后网站自动更新。** push 之后 GitHub 会自动生成网页，1～3 分钟后网站就变了，你什么都不用做。

```
写文章（本地） → 预览（本地） → git push → GitHub 自动生成网页 → 网站更新
```

## 2. 打开终端

所有命令都要在**博客文件夹里**执行。两种方法任选：

## 3. 写一篇新文章（完整流程）

以写一篇“线性代数第一章笔记”为例。

**第 1 步：起一个英文文件夹名**
文件夹名会成为网址，例如 `linear-algebra-ch1` → 网址是 `https://myess121.github.io/p/linear-algebra-ch1/`。
规则：英文小写字母、数字、短横线 `-`，不要空格和中文。

**第 2 步：创建文章**

```powershell
hugo new content post/linear-algebra-ch1/index.md
```

看到 `Content "...index.md" created` 就成功了。

**第 3 步：打开文件编辑**
用 VS Code 打开 `content/post/linear-algebra-ch1/index.md`，开头已经有模板，按第 4 节填写，然后在下面写正文。

**第 4 步：本地预览**（见第 9 节）

```powershell
hugo server -D
```

浏览器打开 <http://localhost:1313/>，边写边看效果。

**第 5 步：写完后把 `draft: true` 改成 `draft: false`**
不改的话文章不会出现在正式网站上。

**第 6 步：发布**（见第 10 节）

```powershell
git add .
git commit -m "新文章：线性代数第一章"
git push
```

等 1～3 分钟，刷新网站就能看到。

> 不想用命令也可以：直接复制一个已有文章的文件夹，改文件夹名，再改里面的 `index.md`。完整模板见 `docs/文章模板.md`。

## 4. 文章开头的“文章信息”怎么填

每篇 `index.md` 最上面两行 `---` 之间的部分叫“文章信息”（front matter），告诉网站这篇文章的标题、日期、分类等。

```yaml
---
title: "线性代数第一章：行列式"
description: "行列式的定义、性质和计算方法"
slug: "linear-algebra-ch1"
date: 2026-11-01T20:00:00+08:00
image: cover.jpg
categories:
    - 学学习
tags:
    - 线性代数
    - 课程笔记
draft: false
---
```

| 字段 | 含义 | 必填吗 |
| --- | --- | --- |
| `title` | 文章标题 | 必填 |
| `description` | 一句话简介，显示在首页卡片上 | 建议填；不填会自动截取正文开头 |
| `slug` | 网址最后一段 | 用命令创建时自动填好 |
| `date` | 发布时间 | 自动填好。**写成未来的时间，文章不会显示** |
| `image` | 封面图文件名，图片要放在同一文件夹 | 可选，不要就删掉这行或留空 |
| `categories` | 分类，见第 5 节 | 建议填 |
| `tags` | 标签，见第 5 节 | 可选 |
| `draft` | `true` = 草稿，不发布；`false` = 发布 | 必填 |

注意：
- 冒号后面要有一个**英文空格**：`title: 标题` ✅　`title:标题` ❌
- `categories`、`tags` 下面每一项前面是 **4 个空格 + 短横线 + 空格**
- 标题里有英文冒号 `:` 时，整个标题用英文双引号包起来

## 5. 分类和标签

### 分类：两个，二选一

| 分类 | 放什么 |
| --- | --- |
| **学学习** | 课程笔记、科研记录、编程技术 |
| **碎碎念** | 大学生活、日常随想 |

写法：

```yaml
categories:
    - 碎碎念
```

分类名必须**一字不差**，写错（比如写成“学习”）会自动多出一个新分类。

### 标签：随便写

标签用来细分主题，比如“高等数学”“Python”“社团”。不用提前创建，在文章里写上，发布后网站自动生成标签页面。

```yaml
tags:
    - 高等数学
    - 期末复习
```

### 怎么管理

- **改某篇文章的分类/标签**：打开它的 `index.md` 改这几行，再发布
- **删掉一个标签**：从所有用到它的文章里删掉，它就自动消失
- **给标签改名**：在 VS Code 里按 `Ctrl+Shift+H`（全局替换），把旧名字替换成新名字
- **看看用过哪些标签**：本地预览时打开 <http://localhost:1313/tags/>
- **新增一个分类**：需要在 `content/categories/` 里新建同名文件夹和 `_index.md`（可以复制 `碎碎念` 文件夹改名，再改里面的 `title`）

## 6. 正文怎么写：Markdown 速查

| 想要的效果 | 写法 |
| --- | --- |
| 二级标题（会进目录） | `## 标题` |
| 三级标题 | `### 小标题` |
| **加粗** | `**加粗**` |
| *斜体* | `*斜体*` |
| `行内代码` | `` `代码` `` |
| 链接 | `[显示文字](https://example.com)` |
| 无序列表 | `- 内容` |
| 有序列表 | `1. 内容` |
| 引用 | `> 引用内容` |
| 分割线 | `---`（单独一行，上下空一行） |

**段落**：段落之间空一行。只按一次回车不会换行。

**正文从二级标题 `##` 开始**。文章标题已经是一级标题，右侧目录会自动根据 `##`、`###` 生成。

**表格**：

```markdown
| 姓名 | 成绩 |
| --- | --- |
| 张三 | 90 |
```

**代码块**（写上语言名会自动上色）：

````markdown
```python
print("Hello")
```
````

常用语言名：`python`、`c`、`cpp`、`java`、`matlab`、`powershell`、`bash`。

## 7. 插入图片

1. 把图片**复制到文章文件夹里**（和 `index.md` 放一起）
2. 在正文里写：

```markdown
![图片说明](图片文件名.png)
```

**设为封面**：在文章信息里写 `image: 图片文件名.jpg`。

注意：
- 文件名建议用英文和数字，例如 `fig1.png`，不要用空格
- **大小写要完全一致**：文件叫 `Fig1.PNG`，就不能写成 `fig1.png`（本地看着正常，上线会裂图）
- 手机拍的照片很大，建议先压缩到 1 MB 以内，加载更快

## 8. 写数学公式

已经全站开启，直接写 LaTeX：

**行内公式**：用一对 `$` 包起来

```markdown
勾股定理 $a^2 + b^2 = c^2$ 很简单。
```

**独立成行的公式**：用一对 `$$` 包起来，单独成段

```markdown
$$
\int_0^1 x^2 \,\mathrm{d}x = \frac{1}{3}
$$
```

**矩阵、多行公式**也可以：

```markdown
$$
A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}
$$
```

小提示：
- `$$` 上下最好各空一行
- 公式里的 `\\` 换行正常写就行
- 如果本地预览公式不显示，检查 `$` 是否成对

## 9. 本地预览

```powershell
hugo server -D
```

- 浏览器打开 <http://localhost:1313/>
- 保存文件后浏览器**自动刷新**
- `-D` 表示连草稿一起显示（正式网站不会显示草稿）
- 结束预览：在终端按 `Ctrl + C`
- 预览期间终端不能输入其他命令，要发布的话先 `Ctrl + C` 停掉，或者再开一个终端

## 10. 发布到网站

在博客文件夹的终端里依次执行：

```powershell
git add .
```
（把所有改动加入“待提交”）

```powershell
git commit -m "这里写这次改了什么"
```
（保存一个版本，引号里写说明，比如“新文章：xxx”“修改错别字”）

```powershell
git push
```
（上传到 GitHub）

然后：
1. 打开 <https://github.com/Myess121/Myess121.github.io/actions>
2. 最上面一条是刚才的发布，黄色圆圈 = 正在生成，**绿色对勾 = 成功**，红色叉 = 失败（见第 13 节）
3. 成功后刷新 <https://myess121.github.io/>，看不到变化就按 `Ctrl + F5`

**发布前检查**：`draft: false` 改了吗？日期是不是未来？本地预览正常吗？

**想先看看改了哪些文件**：

```powershell
git status
```

## 11. 修改或删除已发布的文章

**修改**：直接改对应文件夹里的 `index.md`，然后按第 10 节发布。

**暂时隐藏**：把 `draft` 改成 `true`，发布。

**彻底删除**：删掉整个文章文件夹（例如 `content/post/linear-algebra-ch1`），然后按第 10 节发布。
（删了也能找回：所有历史版本都在 Git 里，需要时找 Claude 帮忙恢复。）

**删除示例文章**：《我的博客搭建记录》在 `content/post/blog-setup/`，不需要时删掉这个文件夹。

## 12. 修改个人信息

| 想改什么 | 文件 | 改哪里 |
| --- | --- | --- |
| 博客名（侧边栏昵称、标签页名） | `config/_default/config.toml` 和 `config/_default/_languages.toml` | `title = "Myess"` |
| 侧边栏简介 | `config/_default/params.toml` | `subtitle = "..."`，`\n` 表示换行 |
| 头像 | `assets/img/avatar.jpg` | 用新图片替换，文件名不变，建议正方形 |
| 浏览器标签页图标 | `assets/img/` + `params.toml` | 放一张新图片，**换个新文件名**，再改 `favicon = "img/新文件名.png"`（不换名字浏览器会一直显示旧图标） |
| 头像右下角小图标 | `config/_default/params.toml` | `emoji = ""`，填一个表情就会显示，留空不显示 |
| 关于我 | `content/page/about/index.md` | 直接改正文 |
| 侧边栏 GitHub 链接 | `config/_default/menu.toml` | `url = "..."` |
| 文章底部版权声明 | `config/_default/params.toml` | `[article.license]` 下的 `default` |

改完先本地预览，满意后按第 10 节发布。

## 13. 常见问题

**终端说 `hugo` 不是内部或外部命令**
→ 关掉终端重新打开。还不行就重新安装：`winget install Hugo.Hugo.Extended`

**文章本地能看到，网站上没有**
→ 依次检查：① `draft` 是不是 `false`；② `date` 是不是未来时间；③ 有没有 `git push`；④ Actions 页面是不是绿色对勾。

**Actions 显示红色叉（发布失败）**
→ 点进那条记录，再点红色的步骤，看报错。最常见是文章信息格式写错（冒号后没空格、缩进不对、引号没配对）。改好后重新发布。看不懂报错就截图发给 Claude。

**`git push` 报错 rejected**
→ GitHub 上有你电脑上没有的改动。先执行 `git pull`，再 `git push`。

**`git push` 要求登录**
→ 按弹出的窗口用 GitHub 账号登录授权即可，只需一次。

**`git commit` 提示 nothing to commit**
→ 没有改动或忘了保存文件。先在 VS Code 里保存（`Ctrl + S`）。

**图片不显示**
→ 图片是否和 `index.md` 在同一文件夹；文件名（含大小写、扩展名）是否完全一致。

**公式没有变成公式**
→ `$` 或 `$$` 是否成对；块级公式 `$$` 是否单独成行。

**本地预览端口被占用（1313）**
→ 已经有一个预览在运行。找到那个终端按 `Ctrl + C`，或者用 `hugo server -D -p 1314` 换端口。

**网站改了但我看到的还是旧的**
→ 按 `Ctrl + F5` 强制刷新；网站图标的缓存最顽固，见第 12 节换文件名的方法。

**搞乱了想撤销所有还没提交的改动**
→ 先别慌，找 Claude 帮忙。不要随手执行网上搜到的 `git reset --hard` 之类的命令。
