## 2026-10-31 初始化博客

**做了什么**

- 基于官方 Starter 完成个人化配置：网址改为 `https://Myess121.github.io/`，界面语言改为简体中文（`zh-cn`），开启中文字数统计（`hasCJKLanguage`）。
- 侧边栏 GitHub 链接指向 `https://github.com/Myess121`，删除 Twitter 链接。
- 关闭评论系统（删除 Disqus 配置，`comments.enabled = false`）。
- 全站开启 KaTeX 数学公式（`article.math = true`）。
- 主题更新工作流 `update-theme.yml` 改为仅手动触发。
- 删除 Starter 自带的 5 篇英文示例文章和示例分类。
- 新建 5 个分类：学习笔记、科研记录、编程技术、大学生活、其他。
- 新建示例文章《我的博客搭建记录》（`content/post/blog-setup/`），测试标题、目录、表格、代码、图片、行内与块级公式。
- 菜单与页面名称中文化（首页、归档、搜索、友情链接）。
- 站点语言代码设为 `zh`（主题的中文翻译文件名是 `zh.toml`，写 `zh-cn` 会导致“目录”等文字缺失）；日期格式改为 `2006-01-02`（即“年-月-日”，原格式会显示英文日期）。
- 新增文章模板 `archetypes/post.md`、`README.md`（中文使用说明）、`AGENTS.md`（接手说明）、本日志。

**为什么**

- 每日自动更新主题会让 GitHub 自动往仓库提交代码，本地再 push 时容易冲突，对新手不友好。
- Disqus 在国内访问困难，且项目不使用评论系统。

**涉及文件**

`config/_default/*.toml`、`.github/workflows/update-theme.yml`、`content/`、`archetypes/`、`README.md`、`AGENTS.md`、`docs/更新日志.md`

**验证**

本地 `hugo --gc --minify` 构建成功，无 ERROR；示例文章中 KaTeX、目录、表格均正常生成。

**遗留事项**

- 博客标题、一句话简介仍为 `【待填写】` 占位，头像仍是模板图片。
- 需要站主在 GitHub 仓库 Settings → Pages 中把 Source 设为 GitHub Actions。
- 本次修改尚未 push。
