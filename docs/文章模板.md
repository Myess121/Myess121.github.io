# 文章模板（可直接复制）

推荐用命令自动生成（会自动填好日期）：

```powershell
hugo new content post/文件夹名/index.md
```

文件夹名会成为网址的一部分，建议用英文小写和短横线，例如 `linear-algebra-ch1`。

也可以手动新建 `content/post/文件夹名/index.md`，把下面整段复制进去：

````markdown
---
title: "文章标题"
description: "一句话简介，会显示在首页文章卡片和搜索引擎结果里"
slug: "linear-algebra-ch1"
date: 2026-10-31T20:00:00+08:00
image: cover.jpg        # 封面图，放在同一文件夹；不需要就删掉这一行
categories:
    - 学学习             # 二选一：学学习、碎碎念
tags:
    - 线性代数
    - 课程笔记
math: true             # 有公式才写 true，没有就写 false 或删掉这行
draft: false            # true = 草稿，不会发布到正式网站
---

## 第一部分

正文。**加粗**、*斜体*、`行内代码`、[链接](https://gohugo.io/)。
````

## 常用字段说明

| 字段 | 作用 |
| --- | --- |
| `title` | 文章标题 |
| `description` | 摘要；不写则自动截取正文开头 |
| `slug` | 网址最后一段，最终地址是 `/p/slug/` |
| `date` | 发布时间。**写成未来时间的文章不会发布** |
| `image` | 封面图文件名 |
| `categories` | 分类（一篇文章一般只选一个） |
| `tags` | 标签，可以随意写多个 |
| `draft` | 是否草稿 |
| `math` | 文章里有公式时必须写 `math: true`，否则公式显示成原始代码 |
| `toc: false` | 关闭本文的目录 |
